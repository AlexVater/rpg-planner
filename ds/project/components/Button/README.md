# Button

Botões em Roboto Condensed bold, cantos de 3px. Um **primário** (`crimson-500`) por região.

| Classe | Uso |
| --- | --- |
| `gr-btn gr-btn--primary` | “+ Nova nota”, confirmar diálogo |
| `gr-btn gr-btn--secondary` | Exportar JSON, Cancelar |
| `gr-btn gr-btn--ghost` | Ações discretas na barra lateral (Importar) |
| `gr-btn gr-btn--danger` | Excluir nota. Sempre abre um `Dialog` |
| `gr-icon-btn` | Fechar painel, ações só de ícone. Exige `aria-label` |

Modificadores: `gr-btn--block` (largura total, usado em “+ Nova nota” na barra lateral) e `gr-btn--sm`.
