# SearchField

Campos sobre `bg-300` com borda `line-300` (3:1). No foco, a borda e um anel de 1px ficam `gold-400`.

- `.gr-search > .gr-icon + .gr-input`: busca da barra lateral.
- `.gr-label` + `.gr-select`: os dois campos lado a lado do painel (`.gr-row`).
- `.gr-textarea`: o modo Editar, em `ui-editor`.

O consumidor liga `<label>` ao campo e fornece o placeholder.
