# SectionHeading

Cabeçalho de seção em versalete `label-caps`, `crimson-400`, com um filete `line-100` até a borda. É a assinatura do sistema, inspirada nos cabeçalhos de compêndio.

Use para *Tipos*, *Notas*, *Sub-notas*, *Citada em* e *Tags*. O contador opcional vai em `<span class="gr-count">`. Escreva o texto em caixa normal, porque o CSS já faz a transformação.
