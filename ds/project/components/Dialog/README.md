# Dialog

Diálogo modal sobre um véu (`.gr-scrim`), com filete superior `crimson-500` e `shadow-panel`.

- **Excluir nota**: título “Excluir *Taverna do Javali*?”. Diga quantas sub-notas ficam órfãs e quantos links viram fantasmas. O botão de confirmação é `gr-btn--danger`.
- **Importar JSON**: “Substituir a campanha?”, com o número de notas que se perdem.

O foco vai para Cancelar ao abrir, e Esc fecha. O consumidor cuida do foco preso.
