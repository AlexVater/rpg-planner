# EmptyState

Estados vazios centralizados: um selo tracejado com ícone, título em Cinzel, uma frase em `ink-300` e, quando faz sentido, uma ação.

- **Carregando**: `.gr-spinner` (ou linhas `.gr-skeleton` na lista). Respeita `prefers-reduced-motion`.
- **Campanha vazia**: no centro do grafo, com “+ Nova nota”.
- **Busca vazia**: na lista da barra lateral, repetindo o termo buscado.
